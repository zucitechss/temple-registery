Notification Pipeline

Temple Registry · Outbox Pattern · SSE + Email Delivery · Event-Driven Architecture

Outbox Pattern Benefits

At-least-once delivery — Events persisted atomically with business transaction

Decoupled dispatch — Async poller, no blocking

Retry resilience — Failed notifications retried 3x with exponential backoff

Audit trail — All notifications logged with status

SSE Implementation

Endpoint: GET /api/v1/sse/subscribe

Auth: JWT via ?token= query param
(cookies don't work for SSE cross-origin)

Client: EventSource API with auto-reconnect

Frontend: useSseNotifications() hook
