Architecture Overview

Spring Boot 3.4.4 backend with JWT authentication, workflow engine, and event-driven architecture. Built on Java 21 with MySQL database and comprehensive domain-driven design.

Technology Stack

Framework: Spring Boot 3.4.4 (Java 21)
Database: MySQL with Flyway migrations
Security: JWT (RS256), Spring Security
ORM: Spring Data JPA / Hibernate
Additional: Async, Scheduling, AOP, Mail
Documents: Thymeleaf, iText PDF, OpenCSV
Testing: JUnit 5, Testcontainers, jqwik
Auth: TOTP MFA Support

Key Architectural Patterns

🎯 Design Patterns
  • Workflow Engine for state machine management
  • Outbox Pattern for reliable notifications
  • Multi-tenancy via District jurisdiction
  • Policy-based access control
  • Event-driven with @TransactionalEventListener
  • Read model optimization (TempleSearchSummary)

🔐 Security Components
  • JwtAuthenticationFilter: Extracts JWT from header, cookie, or query param
  • OwnershipGuard: Verifies user owns the temple entity
  • JurisdictionGuard: Enforces district-based access control

  • TokenRevocationGuard: Validates refresh token status

  • Outbox Pattern: Guaranteed delivery even on system failure
  • Multi-Channel: In-app, email, and real-time SSE
